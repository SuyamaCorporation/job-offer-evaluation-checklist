# Job Offer Evaluation Decision Checklist

A weighted scoring checklist for evaluating job offers across six key factors: salary, benefits, growth opportunity, company culture, commute/remote flexibility, and work-life balance. Rate each factor 1–5 and set personal importance 1–3 to compute a weighted score out of 100 with a recommendation.

## Features

- Six weighted evaluation factors covering all major job offer dimensions
- Rating buttons (1–5) and importance weight buttons (1–3) per factor
- Real-time weighted score calculation out of 100
- Color-coded recommendation: Strong / Decent / Weak / Poor offer
